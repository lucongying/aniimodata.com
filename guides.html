Guides攻略

Where the written guides go: how a system works and what to do about it, kept apart from the tables you look a name up in.写出来的攻略放这里：一个系统怎么运转、碰上它该怎么做 —— 和那些用来查名字的表分开。

This page is a framework这一页目前只有框架

We build the page and the route before the guide that goes on it, so every button in the top bar goes somewhere real. What is on this page today is the plan for it — nothing here is a claim about the game. The values we have checked are in the table on the front page.我们先把页面和路径搭好，再往里填攻略 —— 这样导航栏上每个按钮都指向一个真正存在的页面。今天这一页上写的只是这一页的计划，不是对游戏的任何断言。我们核对过的数值都在首页那张表里。

What will be on this page这一页会有什么

  • An index of every guide on the site, with a line under each one saying which question it answers, so a reader can tell in one screen whether the answer is here.站内每一篇攻略的索引，每条底下写一行它回答的是哪个问题，读者一屏之内就能判断答案在不在。
  • The step-by-step pieces that do not fit inside a table page — the ones that walk a system through in order instead of listing what it contains.那些塞不进数据页的、一步步来的文章 —— 把一套系统按顺序走一遍，而不是把它的内容列成表。
  • A stated split between written and unwritten, because a section that is quietly thin reads as one that was never planned.把「写完的」和「还没写的」明着分开，因为悄悄变薄的一栏，读起来像是从头就没打算做。

While it is being written写出来之前
