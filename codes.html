Redeeming one怎么兑一个

The path is the same on PC, console and phone — only the button that opens the menu changes. On PC that button is Escape.PC、主机、手机上的路径一样，只有打开菜单的那个键不同。PC 上是 Escape。

  1. 01

    Open the menu打开菜单

    Escape on PC, or the ball icon in the top-right corner on a phone. The settings cog is on the right-hand bar.PC 上按 Escape，手机上是右上角的球图标。设置齿轮在右侧那条栏上。

  2. 02

    Settings, then AccountSettings，然后 Account

    Anything tied to your login lives under Account.跟登录账号绑的东西都在 Account 里。

  3. 03

    Gift Code Redemption

    This is the button; the field is labelled Enter redeem code. Paste rather than type — these codes are case-sensitive, and a wrong capital is the most common way to fail at this.就是这个按钮，输入框写的是 Enter redeem code。粘贴，别手打 —— 这些码区分大小写，一个大写字母打错是最常见的失败原因。

  4. 04

    Redeem, then open your Mail兑完去开邮箱

    The reward does not land in your inventory. It arrives as a letter in the in-game Mail, and you have to open it and claim the attachment.奖励不会直接进背包。 它会变成游戏内邮箱里的一封信，你要去把附件领出来。

  5. 05

    Do not expect it in the first hour别指望第一小时就能用

    The box takes a code from early on, but the mailbox — where the reward actually lands — only opens once the opening story has sent you to Bloomville, about the first hour of play. Some accounts report the box itself staying locked until then as well. Either way a rejection on a brand-new account is usually this rather than a dead code.兑换框很早就收码，但奖励真正落地的邮箱，要等主线把你送到 Bloomville 才开 —— 大约开局第一小时。也有人报告说兑换框本身在那之前一直是锁的。两种情况里，全新账号被拒通常都是这个原因，而不是码死了。

When a code says no码说不行的时候

Only three things cause this, and just one of them is the code's fault.只有三种原因，其中只有一种是码自己的问题。

  • The capital letters. These codes are case-sensitive — ANIIMOGIFT and aniimogift are two different strings, and only one of them is a code. Copy and paste it.大小写。 这些码区分大小写 —— ANIIMOGIFT 和 aniimogift 是两个不同的字符串，只有一个是码。复制粘贴。
  • The Mail is not open yet. A new account can paste a live code into the box and get nothing it can use, because the reward is a letter and the letter has nowhere to go. This is the one that looks like a dead code and is not.邮箱还没开。 新账号可以把一个活着的码贴进兑换框，却拿不到任何能用的东西，因为奖励是一封信，而信没有地方可去。这一种最像死码，其实不是。
  • It is actually gone. aniimowelcome and aniimoparty both went this way — retired not by a date but by hitting a redemption cap, which is how a code can be dead while an older list still carries it. Codes announced in a livestream or a single event are the fastest to go.它真的没了。 aniimowelcome 和 aniimoparty 都是这么没的 —— 不是被日期下架，而是撞上了兑换上限；所以一个码可以已经死了，旧清单上却还挂着它。直播里发的、单个活动里发的，死得最快。

The other code that is not a code另一个不是码的码

Aniimo Together was a web event, and the code it handed out was never a gift code — it was an invitation. Pasting one into Gift Code Redemption did nothing; it existed so other players could join your squad on the event page. The launch window it ran in closed on September 27, 2026.Aniimo Together 是个网页活动，它给的那个码从来不是礼品码，是邀请。贴进 Gift Code Redemption 不会有任何结果；它只用来让别人在活动页面上加入你的小队。它所在的开服窗口已在 2026 年 9 月 27 日关闭。

  • Six players, one Aniipod Ultra each. A squad was six people, and a full squad owed every member one Aniipod Ultra — settled after the event closed rather than paid out while it ran.六个人，每人一个 Aniipod Ultra。 一个小队是六人，满员时每个成员有 一个 Aniipod Ultra —— 在活动结束后才结算，活动期间不发。
  • The two pay differently. A gift code pays you immediately, in the game. A squad code paid a whole group, later, on a website — which is the difference worth knowing before you conclude a code is broken.两种码给的路径不同。 礼品码当场给你，在游戏里；小队码给一整队人，晚一点，在网页上 —— 在断定一个码坏了之前，这个区别值得知道。
